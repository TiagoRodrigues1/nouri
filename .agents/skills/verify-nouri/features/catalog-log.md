# Log a catalog food

Choose `2026-09-25` with the `Choose log date` picker. Choose `+ Log` in the sidebar, then `Food`. The dialog opens on its `Recent` tab, so choose the `Search foods` tab, fill `#search-query` with `apple` and press Enter, and select `[aria-label="Food search results"] button:has-text("Apple, flesh and skin, raw")`. Fill `#search-amount` with `150` (the preview below it starts with `81 kcal`), capture a screenshot, and press Enter in `#search-amount` (or choose `Add to log`). The dialog closes, the `Logged foods` list shows the apple at 150 g and 81 kcal, and the summary increases by 81 kcal. Save an authenticated `GET /v1/days/2026-09-25` response and check its catalog reference and nutrients.

The dialog's `Time eaten` picker (`#food-time`, a popover trigger) is shared by all four tabs (Recent, Search foods, Meals, Add manually) and resets to the current local time each time the dialog opens. Click it, then `button[aria-label="Hour 08"]` and `button[aria-label="Minute 15"]`, and press Escape (this closes only the popover). The trigger reads `08:15`; after saving, the stored `occurredAt` is 08:15 local time on the chosen date.
