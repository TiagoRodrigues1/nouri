# Log a catalog food

Choose `2026-09-25` with the `Choose log date` picker. Choose `+ Log` in the sidebar, then `Food`. The dialog opens on its `Recent` tab, so choose the `Search foods` tab, fill `#search-query` with `apple` and press Enter, and tick the `Select Apple, flesh and skin, raw` checkbox. The apple joins the `Selected foods` list below the tabs at 100 g. Fill its `Amount of Apple, flesh and skin, raw in g` with `150` (its line changes to start with `81 kcal`), capture a screenshot, and choose `Log 1 food`. The dialog closes, the `Logged foods` list shows the apple at 150 g and 81 kcal, and the summary increases by 81 kcal. Save an authenticated `GET /v1/days/2026-09-25` response and check its catalog reference and nutrients.

The dialog's `Time eaten` picker (`#food-time`, a popover trigger) is shared by all four tabs (Recent, Search foods, Meals, Add manually) and resets to the current local time each time the dialog opens. Click it, then `button[aria-label="Hour 08"]` and `button[aria-label="Minute 15"]`, and press Escape (this closes only the popover). The trigger reads `08:15`; after saving, the stored `occurredAt` is 08:15 local time on the chosen date. Typing works too: with the popover open, type `0815` and it sets 08:15 and closes; `12` alone sets the hour, and Enter closes. Both lists scroll with the mouse wheel and touch even inside the dialog.
