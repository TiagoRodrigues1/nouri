# Connect or disconnect

Open `/` and choose `Connect your log` in the sidebar. Fill `#api-token` inside the dialog with the run token, then choose the dialog's `Connect` button. The `Personal space` status becomes `Connected`, and the day's entries load. Reload to check session persistence. Choose `Connection settings` in the sidebar and `Disconnect` to clear the token.

For a rejected token, connect with an incorrect value and check for `API token rejected. Check it and connect again.` in the connection dialog. Never print or save the real token in snapshots or command output.
