# Search foods

Connect, choose `Log a food`, and use the `Search foods` tab. Fill `#search-query` with `apple` and press Enter. Search for a misspelling such as `chiken` to check that typo-tolerant results appear. The `Food search results` list includes `Apple, flesh and skin, raw`, and the dialog includes the Anses source link. Search for `zzzznotfood` to check the no-match message. Capture screenshots before and after the action and use the authenticated search API as a second read if needed.
