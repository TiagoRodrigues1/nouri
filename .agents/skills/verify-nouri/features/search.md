# Search foods

From any page, press `Ctrl+K` (or choose `+ Log` in the sidebar), then `Log food` (see [command-palette.md](command-palette.md)). Type `apple`; results appear under `Foods` once typing pauses. The meal editor's `Search` tab on the Meals page searches the same way with `#search-query` and Enter (see [Meals](saved-meals.md)). Search for a misspelling such as `chiken` to check that typo-tolerant results appear. Search for `peito de frango` to check Portuguese search: the first result is `Chicken, breast, without skin, raw`, shown under its English Ciqual name. The results include `Apple, flesh and skin, raw`. No source link shows for Ciqual results. Search for `zzzznotfood` to check the no-match message, `No foods found. Try another name.` Capture screenshots before and after the action and use the authenticated search API as a second read if needed.

Regression checks: `no sugar` must rank "Tea, brewed, no added sugars" first; `frango cru` and `frnago cru` must both rank "Chicken, meat, raw" first. `maçãs cruas` must include "Apple, flesh and skin, raw", and `couves-flores` must rank "Cauliflower, raw" first.
